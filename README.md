# SQL LeetCode Practice

This repository contains my personal SQL solutions for LeetCode problems, focused on improving query-writing skills and database reasoning.

As a backend developer, practicing SQL helps me write more efficient queries, understand data relationships better, and work more effectively with ORMs and database-driven applications.

## 🧠 Skills Covered

- Joins
- Aggregations and grouping
- Subqueries
- Window functions
- Conditional logic with `CASE WHEN`
- Date and time analysis
- Filtering, ranking, and data cleaning

## 🛠️ Tools and Database Focus

- MySQL
- PostgreSQL concepts
- SQL problem-solving patterns used in technical interviews and real-world backend work

## 📁 Repository Structure

Each file is named by the problem title or number and contains a SQL solution for that challenge.
